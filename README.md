# 📚 StudyFlow AI

An AI-powered study assistant built with **React**, **TypeScript**, **Vite**, **Tailwind CSS**, **Zustand**, and **Framer Motion**.

StudyFlow AI helps students stay organized, focused, and productive through smart study tracking, Pomodoro sessions, progress analytics, and AI-powered learning tools.

---

## ✨ Features

### 🎯 Productivity

- Pomodoro Focus Timer
- Ambient Study Sounds
- Daily Study Goals
- Progress Tracking
- Study Streak Counter

### 📊 Dashboard

- Daily Overview
- Quick Actions
- Weekly Progress Charts
- Study Statistics
- Recent Activity

### 📈 Progress Analytics

- Learning Progress
- Achievement System
- Goal Tracking
- Study Insights
- Performance Metrics

### ⚙️ Personalization

- Dark / Light Theme
- Custom Study Preferences
- Notification Settings
- Focus Session Configuration

### 📱 Progressive Web App (PWA)

- Installable on Desktop & Mobile
- Offline Support
- Fast Loading
- Responsive Design

# 💻 Getting Started

## Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/StudyFlow-AI.git
```

## Install dependencies

```bash
npm install
```

## Start development server

```bash
npm run dev
```

## Build production version

```bash
npm run build
```
